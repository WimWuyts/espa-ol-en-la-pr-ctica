# Español en la práctica — cursusproject Spaans (D-finaliteit, KOV)

Samenhangend cursuspakket Spaans voor de 2de en 3de graad doorstroomfinaliteit,
gebaseerd op het leerplan **III-Spa-d** (Katholiek Onderwijs Vlaanderen).

## De vier cursussen

| Code | Jaar | Rol | Kleur |
|------|------|-----|-------|
| **C4** | 4 Moderne talen | «Welcome to Spanish» (buiten leerplan, videogedreven) | 🔴 rood |
| **C5** | 5de | Kerncursus, A1 → eerste A2 | 🟢 groen |
| **C6** | 6de (nieuw) | Clean vervolg, A2 → aanzet B1 | 🔵 blauw |
| **C6+** | 6de (huidig) | Vervolg op de oude cursus *Español en la práctica* | 🟣 paars |

Elke unit verschijnt in **vier formaten** met identieke, uitgeverswaardige layout:
**Word · PDF · PowerPoint · interactieve HTML**.

## Structuur

- `CLAUDE.md` — projectgeheugen (context, afspraken, huisstijl). **Lees dit eerst.**
- `00-brondocumenten/` — leerplan, outlines, oude cursus, video's, gap-analyse.
- `01-cursussen/` — de vier cursussen (bron/content).
- `02-huisstijl/` — gedeelde templates, kleuren, fonts, componenten.
- `03-build/` — gegenereerde output.

## Werkwijze

Setup → analyse/gap-analyse → **golden sample** (één unit in alle formaten, goedkeuren) → productie.
